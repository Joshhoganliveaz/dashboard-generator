    **UI Layout:**
    1. **Upload section:**
       - File drop zone or click-to-upload for MLS PDF
       - Accept only `.pdf` files
       - Show file name after selection
       - "Extract" button to trigger Claude extraction
       - Loading/progress state during extraction

    2. **Extraction flow:**
       - On "Extract" click: create FormData with the PDF, POST to `/api/dashboard/generate` with `templateType` and `extractOnly=true` flag
       - OR: simpler approach -- call the extraction API directly. The existing `askClaudeWithPDF` function in `claude-api.ts` is server-side only. Create a small API route `POST /api/dashboard/extract-mls` that accepts the PDF FormData, calls `extractMLSData()` from `claude-api.ts`, and returns the structured JSON.
       - While extracting, show spinner with "Extracting property details from MLS listing..."

    3. **Editable fields panel (after extraction or for manual entry):**
       - Display all extracted MLS fields as editable inputs: address, city/state/zip, beds, baths, sqft, lot_sqft, year_built, pool (checkbox), stories, estimated_sale_price
       - Pre-fill from extraction results OR from existing sell_data if returning to this step
       - User can correct any value (WIZD-06)
       - If extraction fails, show error toast and display all fields as empty inputs for manual entry (WIZD-07)

    4. **API route:** Create `src/app/api/dashboard/extract-mls/route.ts`:
       - POST handler: accepts FormData with `mlsPdf` file
       - Calls `extractMLSData(file)` from claude-api.ts (or the equivalent structured extraction function)
       - Returns JSON with extracted fields
       - Handles errors gracefully (returns 200 with empty fields + error message)

    **Navigation:**
    - "Back" button: goToStep(2)
    - "Next" button: saves all property fields to sell_data via Supabase, calls goToStep(4)
    - "Skip" link: for cases where no MLS PDF is available, allows advancing with manually entered or empty data

    **Buyer type handling:** If `dashboard.type === "buyer"`, this step should not render.
