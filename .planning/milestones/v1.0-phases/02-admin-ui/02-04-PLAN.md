The existing generation pipeline works in two phases:
1. POST /api/dashboard/generate with FormData (CSV, MLS PDF, etc.) -> SSE stream -> pauses at review_comps
2. POST /api/dashboard/generate/continue with approved comps -> SSE stream -> completes with HTML

The FormData for generate() expects:
- templateType: string
- clientDetails: JSON string with client info
- csv: File (ARMLS CSV)
- mlsPdf: File (optional)
- cromford: File[] (optional)
- taxRecords: File (optional)
