3. Rewrite src/components/wizard/StepPublish.tsx to replace the placeholder publish button with functional actions:

**State additions:**
- `publishing` (boolean) -- loading state for publish action
- `publishedUrl` (string | null) -- URL returned after successful publish
- `copied` (boolean) -- flash state for copy button feedback
- `archiving` (boolean) -- loading state for archive action
- `actionError` (string | null) -- error message from any action

**Publish button:**
- On click: POST to `/api/dashboard/${dashboard.id}/publish`
- On success: set publishedUrl from response.url, show success state
- On error: show error message
- Disable while publishing or if status is "archived" (must un-archive first)
- Label: "Publish Dashboard" (draft) or "Re-Publish Dashboard" (published) or "Un-Archive & Publish" (archived)

**URL display (shown after publish or if dashboard.published_at exists):**
- Show full URL: `${window.location.origin}/d/${dashboard.slug}`
- Copy button that uses `navigator.clipboard.writeText()` and shows "Copied!" for 2 seconds
- Style: green success banner with link icon

**Download button:**
- Opens `/api/dashboard/${dashboard.id}/download` in a new tab (or uses window.location for direct download)
- Always available (renders from DB data, not R2)
- Label: "Download HTML" with download icon

**Archive button (only shown when status is "published"):**
- On click: POST to `/api/dashboard/${dashboard.id}/archive`
- On success: update local state, show archived status
- Confirm dialog before archiving: "Archive this dashboard? The public URL will return 404."
- Style: destructive/red outline button

**Status badge in review summary:**
- Replace the hardcoded "Draft" badge with dynamic status:
  - draft: amber badge "Draft"
  - published: green badge "Published"
  - archived: gray badge "Archived"

Keep existing slug editor, review summary, and back navigation. Keep the "Save & Return to Library" button.
